# Collapsible Groups

Organize items, fluids, and other ingredients into collapsible groups in Minecraft 1.21.1.

Use built-in groups or create your own with the in-game editor, JSON files, resource packs, or KubeJS. Manage, search, and enable groups from one screen.

Supports JEI on Fabric, Forge, and NeoForge, with EMI support on Fabric and NeoForge.
