# Collapsible Groups 2.0.0-beta6 — Minecraft 26.1.2

- Fixed the JEI ingredient sidebar failing to load with recent JEI versions, including JEI 29.53.0.115.
- Fixed the group manager button and its tooltip disappearing when a JEI search returns no results.

**Compatibility:** Requires Java 25 and JEI 29.47.0.110 or newer. Older JEI versions are no longer supported. Use NeoForge 26.1.2.99+, or Fabric Loader 0.19.5+ with Fabric API 0.155.3+26.1.2 or newer. EMI is not supported in this Minecraft version.
