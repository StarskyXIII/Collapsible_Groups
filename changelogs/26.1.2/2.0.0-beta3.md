# Collapsible Groups 2.0.0-beta3 — Minecraft 26.1.2

- Added built-in groups for AllTheCompressed, Botany Pots, Botany Pots Tiers, Productive Bees, and Productive Lib.
- Fixed KubeJS group filters and script reloads on NeoForge.
- Fixed the group preview disappearing when editing an invalid rule.
- Disabled tabs now match the look of other disabled buttons.
- Toggles now stay in place after a click until you move away and hover again.
- Updated compatibility for Minecraft 26.1.2 and JEI 29.43.

**Compatibility:** Requires Java 25 and JEI 29.43.0.106+. Use NeoForge 26.1.2.99+, or Fabric Loader 0.19.5+ with Fabric API 0.155.3+26.1.2 or newer. EMI is not supported in this Minecraft version.
